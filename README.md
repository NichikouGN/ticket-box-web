# ticket-box-web
## Overview
- This `ticket-box-web` provide a website UI for ORGANIZER and AUDIENCE role in https://github.com/NichikouGN/ticket-box-backend.

## Tech Stack
- ReactJS
- Typescript
- TailwindCSS
- ShadcnUI

## Installation
1. Configure the `.env` file

2. At root directory
```
npm install
```
3. Run and open the browser
```
npm run dev
```
